## Sobre o projeto

O **Matheus.dev** é meu portfólio pessoal, desenvolvido com o objetivo de apresentar minha formação acadêmica, meus conhecimentos técnicos, minhas habilidades e os projetos que venho desenvolvendo durante meus estudos na área de Desenvolvimento de Sistemas.

O projeto também faz parte do meu processo de aprendizado em desenvolvimento web, permitindo colocar em prática conceitos de estruturação de páginas, estilização, responsividade e acessibilidade.

## Objetivos

- Apresentar meu perfil como estudante de Desenvolvimento de Sistemas.
- Compartilhar minha formação acadêmica e meus cursos.
- Demonstrar meus conhecimentos técnicos e habilidades.
- Apresentar projetos desenvolvidos durante minha formação.
- Registrar minha evolução e meu aprendizado na área de tecnologia.
- Criar um espaço para apresentar meus trabalhos e experiências acadêmicas.

## Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo das páginas.
- **CSS3:** estilização, cores, layouts, animações e responsividade.
- **JavaScript:** implementação de interações e funcionalidades da interface.
- **Bootstrap 5.3.8:** utilização de recursos e classes para auxiliar na construção do layout responsivo.

## Estrutura do projeto

O portfólio é organizado em páginas que apresentam diferentes informações sobre minha trajetória e meus trabalhos.

| Página | Descrição |
|---|---|
| `index.html` | Página inicial, apresentação pessoal, seção Sobre mim e projetos em destaque. |
| `formacao.html` | Apresentação da minha formação acadêmica e dos cursos realizados. |
| `habilidades.html` | Apresentação dos conhecimentos técnicos, ferramentas e competências. |
| `projetos.html` | Descrição detalhada dos projetos desenvolvidos. |
| `acps.html` | Organização e acompanhamento das Atividades Curriculares de Projetos e Serviços (ACPS). |
| `style.css` | Estilos visuais compartilhados e específicos das páginas. |
| `script.js` | Código JavaScript responsável pelas interações da interface. |
| `images/` | Diretório destinado às imagens utilizadas no portfólio. |

## Funcionalidades

- Navegação entre as páginas do portfólio.
- Menu adaptável a dispositivos móveis, com botão de navegação.
- Seção de apresentação pessoal.
- Exibição da formação acadêmica e dos cursos.
- Organização dos conhecimentos e habilidades em cartões.
- Apresentação de projetos com imagens, descrições e tecnologias utilizadas.
- Página para organização das atividades curriculares.
- Área de contato no rodapé.
- Recursos de acessibilidade, incluindo navegação por teclado e link para pular diretamente ao conteúdo principal.
- Layout responsivo para diferentes tamanhos de tela.

## Responsividade e acessibilidade

O projeto utiliza recursos de CSS e Bootstrap para adaptar a apresentação do conteúdo a diferentes dispositivos, como computadores, tablets e celulares.

Também inclui cuidados com acessibilidade, como indicadores de foco para navegação por teclado, identificação da navegação principal e suporte à preferência do usuário por movimento reduzido.

## Como executar o projeto

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto no seu editor de código.
3. Verifique se os arquivos HTML, `style.css`, `script.js` e a pasta `images/` estão organizados corretamente.
4. Abra o arquivo `index.html` no navegador.

O projeto utiliza HTML, CSS e JavaScript no lado do cliente. O Bootstrap é carregado por meio de uma CDN, portanto, é necessária uma conexão com a internet para carregar esse recurso externo.
